Entry for the [Two Lines to Your Past Self](https://make.fun/bounty/u-suga-two-lines-to-your-past-self-f36c83ca) bounty on make.fun.

The program (`main.ts`) writes two lines of advice to your past self to `/output/entry.txt`:

> Don't send that message at 2 a.m. — you'll regret it by breakfast, and screenshots don't forget.
>
> It mattered because one careless night cost me a friendship, and now I sleep on every angry draft.

## Run

```sh
node main.ts
```

This writes `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
